# Informacioni sistem pozorišta

**Informacioni sistem pozorišta** je dizajniran da modernizuje i olakša upravljanje svim aspektima rada pozorišta. Ovaj sistem integriše ključne poslovne procese, od upravljanja repertoarom i prodaje karata, do organizacije audicija, evidencije tehničke opreme i finansijskog poslovanja.

Projekat je realizovan u okviru kursa **"Informacioni sistemi"** na Matematičkom fakultetu Univerziteta u Beogradu.
